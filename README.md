# 📝 Task Management App

A simple React application for managing tasks. Users can create, read, update, and delete tasks with properties like title, description, due date, and completion status. Includes optional filtering and sorting features.

## 🚀 Features
- **CRUD Operations**: Create, Read, Update, and Delete tasks.
- **Task Properties**: Manage tasks with title, description, due date, and completion status.
- **Filtering & Sorting**: Optionally filter and sort tasks by status or due date.

## 🛠️ Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/task-management-app.git
   cd task-management-app
   ```
   Install dependencies:
```bash
npm install
```
Run the development server:
```bash
npm run dev
```
Open in browser:

The app will be available at http://localhost:5173 (Vite default).
